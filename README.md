# VibeDrop 🎵🎬

Projeto pessoal de aprendizado em Python, Flask, yt-dlp, FFmpeg e desenvolvimento web. Criado para praticar informática e compartilhar a interface com poucos amigos.

## Estado do repositório

**Preparando a publicação experimental na Render Free.** Ainda é necessário subir os arquivos da aplicação (app.py, Dockerfile, requirements.txt, templates/, static/ e tests/) antes de executar o deploy. O arquivo `render.yaml` está configurado para instância gratuita e exige uma senha de acesso no painel da Render.

O código completo preparado para a Render, com visual do VibeDrop 2.0 e manifesto PWA, foi fornecido no ZIP da conversa ChatGPT de 21/10/2026. Leia o guia `GUIA_LANCAMENTO.md` para informações adicionais.

## Tecnologias

- Python + Flask + Gunicorn
- yt-dlp + FFmpeg para mídia própria ou autorizada
- HTML + CSS + JavaScript
- Docker + Render Free
- PWA (instalável no celular por navegadores compatíveis)

## Responsabilidade

Não use o aplicativo para contornar DRM, acessar material privado ou baixar conteúdo sem autorização. Plataformas podem bloquear downloads, especialmente a partir de servidores na nuvem. O plano gratuito tem poucos recursos e pode suspender o serviço se o tráfego for elevado.

Projeto educacional, sem garantia de disponibilidade contínua.
